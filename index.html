Ayuda de MegaControl

Nueva salida te permite cargar un PDF, revisar sus productos y descargar el Excel. Puedes cambiar las columnas, el número de salida y el nombre del archivo.

Archivo de salidas reúne los documentos compartidos. Las unidades se recalculan automáticamente desde cada PDF original, también en las salidas antiguas; Actualizar repite la comprobación. Inicia sesión con tu usuario y contraseña para buscar una salida y guardar su PDF o Excel. En su detalle, Editar Excel permite escoger columnas y nombres usando el PDF guardado, sin subirlo de nuevo ni crear otra salida. Los documentos originales se conservan.

El Excel se descarga una sola vez y muestra una confirmación con su nombre. Para elegir carpeta, activa Preguntar dónde guardar cada archivo en las descargas de Chrome o Edge. Para abrirlo en Excel automáticamente, selecciona Abrir siempre archivos de este tipo en el menú del Excel descargado, si aparece esa opción. Excel debe estar instalado; la página no puede activar ese ajuste por ti.

Para el PDF puedes elegir carpeta desde la app en navegadores compatibles. Descargar una copia permite añadir ese PDF al panel de descargas cuando lo necesites.
