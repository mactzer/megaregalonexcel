2. Ejecuta en Supabase
Abre el SQL Editor del proyecto actual, crea una consulta nueva, pega el SQL y pulsa Run. Se aplica en una transacción. Puedes ejecutarlo otra vez sin borrar datos.
La actualización obliga a usar la nueva reserva de operaciones. Las pestañas antiguas deben recargarse antes de registrar salidas.
Abrir SQL Editor del proyecto


3. Comprueba el equipo
Entra al escáner y pulsa Actualizar en Últimas consultas. Si hay consultas pendientes, pulsa Reintentar guardado. Consulta un producto con una cuenta y comprueba el historial con otra. Recarga, inicia sesión y comprueba que sigue disponible.
Para los registros antiguos: un administrador abre Archivo → Revisar duplicados. Se comparan los PDF completos. Solo vincula las coincidencias que confirmes como la misma operación; los movimientos distintos y los documentos originales se conservan.
